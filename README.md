# 果屿鲜果 · 钟祥演示站

公开的界面与流程审核模板，仅使用演示数据，不处理真实支付、订单、佣金或会员资金。

## 一键部署到 Render

[部署演示站](https://render.com/deploy?repo=https%3A%2F%2Fgithub.com%2Fljivfnaj1b50%2Fpk-new-project%2Ftree%2Fguoyu-demo)

该链接是店铺方的部署入口，不是发给客户的预览链接。先注册/登录自己的 Render 账号，再检查待部署资源并确认。站点类型为静态网站，具体额度、费用与域名以控制台为准。

配置已写入 render.yaml，无需输入构建参数。自动部署关闭，后续更新由店铺方手动确认。

部署成功后，使用 Render 返回的公开HTTPS地址，在实际微信环境检查首页、图片、会员中心、购物车和后台；通过后再生成二维码。默认子域名是否可用以平台分配为准。

如果需要自有品牌域名，可以在部署完成后绑定已注册域名。域名购买及相关服务应另行明确授权。
